# Воин
![воин.jpg](/img/воин.jpg)

*Воины правят полями сражений. Странствующие рыцари, королевские защитники, элитные пехотинцы и суровые наёмники – всех их объединяет несравненное мастерство в обращении с оружием и бронёй. Они хорошо знакомы со смертью: они много раз дарили её другим и не раз сами смотрели ей в лицо. Воины владеют различными оружейными приёмами, хорошо экипированы и всегда имеют подходящий инструмент для любой боевой ситуации. Каждый из них специализируется на определённом стиле боя. Некоторые сосредотачиваются на стрельбе из лука, другие – на сражении сразу двумя оружиями, а кто-то усиливает свои боевые навыки с помощью магии.*

**Образ:** универсальный мастер боя, готовый сражаться любым привычным для него оружием.

**Основное требование к антуражу:** доспешная защита корпуса.

**Оружие:** одноручное и двуручное оружие ближнего боя, стрелковое.

**Защита:** любые доспехи, щиты и баклеры.

**Особенности:** может использовать сразу два одноручных оружия.
